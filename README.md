# Takeoff NSW Formatter (Streamlit App)

This Streamlit web app converts raw HVAC project CSV or Excel files into the **Takeoff NSW** format automatically — with styling, grouping, brand autofill, and export options.

---

## 🚀 Features
✅ Upload any raw CSV or Excel  
✅ Auto-map columns to Takeoff NSW format  
✅ Apply custom BRAND rules (AD-GRD → PRICE, FAN → LOREN COOK, etc.)  
✅ Group, subtotal, and format QTY automatically  
✅ Keep MODEL column blank (optional)  
✅ Replace empty cells with "." (optional)  
✅ Download formatted Excel and CSV instantly
